# elixir

Erlang's VM, Elixir's syntax. Immutable data, lightweight processes, a scheduler for machines that aren't allowed to go down.

## Covered

- `basics.md`: expressions, types, modules, mix
- `control-flow.md`: pattern matching, guards, cond/case/with, recursion, Enum/Stream
- `data-abstractions.md`: modules as abstractions, structs, Access, protocols
- `concurrency.md`: processes, spawn/send/receive, stateful servers
- `generic-server.md`: ServerProcess, behaviours, GenServer, call vs cast
- `concurrent-system.md`: one process per list, cache, bottlenecks, call vs cast
- `fault-tolerance.md`: let it crash, links, monitors, supervisors
- `supervision-trees.md`: isolate errors, registry, DynamicSupervisor, let it crash
- `beyond-genserver.md`: Task, Agent, ETS, single-process bottleneck
