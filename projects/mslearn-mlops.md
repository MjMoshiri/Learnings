# MS Learn: MLOps on Azure

Azure ML hands-on challenges covering the production MLOps loop: experimentation in notebooks, then promoting code to a `src/` layout, pytest for unit tests, GitHub Actions for CI, and Azure ML pipelines for training and deployment.

The valuable part was not Azure-specific. It was the shape of an MLOps pipeline: separating experimentation from production, parameterizing training jobs, versioning artifacts, and testing the bits around the model rather than the model itself.
