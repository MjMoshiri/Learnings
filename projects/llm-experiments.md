# LLM Experiments

Two small experiments to probe LLM behavior:

1. **Rock-paper-scissors prompt order.** Does shuffling the order of options in the prompt change which one the model picks? Short answer: yes, more than it should.
2. **Trust game.** Standard behavioral economics setup. How does an LLM act as the truster and as the trustee? Looking at whether the model is generous, fair, or exploitative depending on framing.

Both are small JSON-result + Jupyter analysis notebooks. The point was less the result and more learning how to design and run repeatable behavioral experiments against a stochastic model.
