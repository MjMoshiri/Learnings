# CS50 (Harvard)

C, then Python, then SQL, then web. Eight weeks of problem sets covering algorithms, memory, data structures, basic security, and a small web stack. First serious exposure to manual memory management and pointer arithmetic.

What stuck:
- Buffer overflows are not abstract once you trip one
- SQL injection makes sense after the lecture, not before
- Rolling your own data structures in C builds intuition that high-level languages flatten
